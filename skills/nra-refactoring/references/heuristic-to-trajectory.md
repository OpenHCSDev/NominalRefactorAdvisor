# Cheap leads → admitted decisions → ordered NRA trajectory

NRA's heuristic output is a **retrieval layer**, not a weaker form of proof.
`SOURCE_BACKED_CONDITION_LEAD` finds a single `if`/`while` test with four or more
direct `and`/`or` terms. `SOURCE_BACKED_ROSTER_LEAD` finds repeated literal
string containers of at least three values in one module; sets compare members,
while tuples/lists compare original order. Both retain original source rows,
are `strong_heuristic`, and have **no executable recipe**. These are inexpensive
ways to select maintenance questions, not an assertion that every long
condition is defective or every matching container is one domain family.
The string-dispatch lead supplies complementary original case witnesses.

For each cluster of leads, the agent should investigate rather than ask the
owner to enumerate all cases:

1. Pin revision, selected production corpus and detector coverage. Read the
   original tests, containers and consumers, including omitted/unaligned rows.
   Record competing owners and the counterexample that would disprove a shared
   authority. Classify each condition term as independent predicate, repeated
   fact, foreign state probe or case selection **from source and domain input**,
   not from its syntax count. A matching roster may instead be an external
   protocol vocabulary; preserve that contract.
2. Present one bounded semantic decision for the whole maintenance object:
   intended answer, proposed public owner/ABC, admitted members and crossing
   capabilities, independently owned cases, the value-only alternative (if
   justified), and exact OPEN rows. State the new-case edit experiment. The
   domain rule or task-authorized specification admits a family; matching
   literals alone never do.
3. Once admitted, compose **one ordered plan for all dependent decisions**:
   declaration and shared behavior; derived membership; migrations of each
   consumer and effectful guard; deletion of mirrors; terminal forbidden-path
   guard. Simulate each stage on projected source, re-resolve next selectors,
   and inspect source revision, binding, initializer effects, MRO, priority,
   short-circuit behavior, external formats, fallback and async order. A
   passing preflight is not behavioral equivalence. A still-OPEN obligation
   blocks applying the combined plan, not exploratory planning.
4. Verify behavior at the actual boundary and the new-case edit count; rerun
   a complete scan at the target revision, report coverage and unresolved
   counterevidence. The plan is not done while a second authority survives.

This is how cheap searches reduce the busy work **before** the real semantic
choice, and how one choice can authorize many deterministic DSL stages. NRA
currently does not infer the choice, automatically join these three heuristic
families into an admitted dossier, or certify arbitrary async source movement.
Do not label this workflow an implemented automatic plan generator.
